# East Harling Bakery — concept preview

An unofficial, non-production redesign concept based on information and publicly visible photos from [the bakery’s website](https://eastharlingbakery.co.uk/). It is not commissioned or approved by the bakery.

The responsive page adds a cozy visual identity, gentle motion, menu details, custom cakes, a photo gallery, and visit information. Photos currently link to the bakery’s public site for discussion only. Confirm all details and photo permissions before adopting the design.
